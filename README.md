# ChatterShade

Change dialogue text and background colors to make conversations easier to read.

## Features

- Separate color settings for standard and dark dialogue windows.
- Tint the original background or use a rounded solid-color background.
- Adjust background opacity when using Solid color mode.
- Change NPC name colors separately from dialogue text.
- Restore the original appearance or apply a dark preset.

## Usage

Use `/cshade` to open the settings.
